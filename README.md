## 🚀 项目概述

**中岳会计管理系统** 是一个功能完整的企业级财务管理综合平台，专为会计服务公司打造。系统涵盖客户关系管理、合同全生命周期、费用控制、人力资源管理、合规性管理等核心业务，为财务服务行业提供一站式数字化解决方案。

### 📊 项目规模

- **代码规模**：164+ TypeScript/React 文件
- **功能模块**：10+ 核心业务模块  
- **页面组件**：56+ 页面相关文件
- **API接口**：20+ 业务API模块
- **自定义组件**：30+ 可复用组件
- **业务覆盖**：客户管理 → 合同签署 → 费用控制 → 薪资管理 → 合规跟踪

## 🏗️ 架构特点

### 模块化设计
```
src/
├── api/           # 20个业务API模块，统一请求封装与错误处理
├── components/    # 30+可复用组件，支持组合模式设计
├── pages/         # 按功能模块组织的页面组件，懒加载优化
├── hooks/         # 20+自定义Hook，数据获取与业务逻辑封装
├── store/         # Zustand状态管理，支持数据持久化
├── types/         # TypeScript类型定义，保障完整类型安全
├── routes/        # 路由配置，支持权限控制和懒加载
└── utils/         # 工具函数库，通用逻辑抽象
```

### 状态管理策略
- **全局状态** - 使用Zustand管理认证状态、表单状态、页面状态
- **服务端状态** - SWR处理数据缓存、重新验证和错误重试
- **页面状态持久化** - 搜索条件、分页参数、Tab状态的本地存储
- **不可变更新** - Immer中间件简化复杂状态的更新逻辑

### 安全性保障
- **多层级认证机制** - JWT + 自动刷新 + 无操作超时 + 密码过期
- **角色权限控制** - `AuthorizedRoute`和`PermissionGuard`组件
- **API请求安全** - 请求拦截器自动添加认证头和错误处理
- **数据传输安全** - HTTPS加密和CORS策略配置

### 性能优化策略
- **路由懒加载** - 所有页面组件实现按需加载
- **智能代码分割** - Vite配置的分包策略，优化加载性能
- **数据缓存机制** - SWR的智能缓存和背景重新验证
- **图片优化** - 图片懒加载、压缩和预览优化

## 🚦 开发环境

### 环境要求
- **Node.js** >= 18.0.0
- **pnpm** >= 8.0.0

### 快速开始

1. **安装依赖**
```bash
pnpm install
```

2. **启动开发服务器**
```bash
pnpm dev
# 默认端口: http://localhost:5173
```

3. **构建生产环境**
```bash
pnpm build
```

4. **预览生产版本**
```bash
pnpm preview
```


## 🐳 Docker部署

### 单容器部署

1. **构建Docker镜像**
```bash
docker build -t zhongyue-react .
```

2. **运行容器**
```bash
docker run -d -p 80:80 --name zhongyue-frontend zhongyue-react
```

### Docker Compose部署

1. **启动服务**
```bash
docker-compose up -d
```

2. **停止服务**
```bash
docker-compose down
```

### 自定义配置

连接自定义API服务器，修改`nginx/nginx.conf`中的`proxy_pass`配置：

```bash
docker run -d -p 80:80 \
  -v /path/to/custom/nginx.conf:/etc/nginx/conf.d/default.conf \
  zhongyue-frontend
```
